# Regras da Prisão

## 1. Respeito ao Ambiente Prisional

A prisão deve ser tratada como um ambiente realista e funcional dentro do roleplay. Mesmo cumprindo a pena em silêncio, o jogador precisa manter coerência com o cenário e com o comportamento esperado de alguém encarcerado.

{% hint style="success" %}
**Exemplo correto:** interagir com guardas, conversar com outros presos, manter uma postura condizente com quem está preso.
{% endhint %}

{% hint style="danger" %}
**Exemplo incorreto:** agir como se nada tivesse acontecido, ignorando completamente o fato de estar preso.
{% endhint %}

## 2. Hierarquia Prisional

A prisão tem hierarquias internas — entre presos, e entre presos e guardas. Essas relações devem ser respeitadas e interpretadas de forma coerente.

{% hint style="success" %}
**Exemplo correto:** um novato que chega à prisão age com cautela, evita confronto imediato com lideranças internas e busca se orientar antes de se impor.
{% endhint %}

{% hint style="danger" %}
**Exemplo incorreto:** chegar impondo liderança instantaneamente, sem qualquer narrativa ou construção prévia.
{% endhint %}

## 3. Empregos e Atividades

Trabalhos prisionais fazem parte da rotina do encarcerado e podem reduzir o tempo de pena. Cabe ao próprio preso decidir entre realizá-los para obter redução ou cumprir a sentença integralmente.

{% hint style="info" %}
**Exemplos:** trabalhar na lavanderia, oficina ou cozinha para reduzir a pena; ou optar por não trabalhar e cumprir a pena integral.
{% endhint %}

## 4. Contrabando e Itens

Contrabando é permitido, desde que plausível e bem interpretado. Um item ilegal só pode existir dentro da prisão quando houver justificativa clara de como ele foi introduzido no ambiente.

{% hint style="success" %}
**Exemplo correto:** subornar um guarda para conseguir um celular, ou improvisar um item a partir de materiais disponíveis na oficina.
{% endhint %}

{% hint style="danger" %}
**Exemplo incorreto:** "tirar do bolso" uma arma ou faca sem qualquer lógica ou explicação de como ela chegou até ali.
{% endhint %}

## 5. Conflitos e Violência

Conflitos entre presos fazem parte da rotina prisional, desde que sejam motivados e realistas. Violência gratuita ou sem propósito é tratada como quebra de roleplay.

{% hint style="success" %}
**Exemplo correto:** um grupo ataca outro depois de semanas de rivalidade construída dentro da prisão.
{% endhint %}

{% hint style="danger" %}
**Exemplo incorreto:** agredir presos aleatoriamente, sem motivo ou construção prévia.
{% endhint %}

## 6. Fugas da Prisão

Fugas são permitidas, mas devem ser raras e cuidadosamente planejadas. Uma fuga sem justificativa plausível é tratada como powergaming.

{% hint style="success" %}
**Exemplo correto:** organizar uma fuga com apoio de uma facção, contrabando prévio e aliados externos.
{% endhint %}

{% hint style="danger" %}
**Exemplo incorreto:** escalar um muro alto sem qualquer equipamento e simplesmente narrar "escapei".
{% endhint %}
